  1. Click Activate Demo Mode — seeds 3 sample files with tamper events
  2. Navigate to Dashboard — show the live forensic activity feed with tamper events
  3. Click Monitored Assets — show the 3 protected files with CLEAN / MODIFIED status badges

  6. Navigate to Forensic Reports — click View Report for a professional incident report
