Seeds 3 realistic sample files into the database — a config file, an auth handler (with backdoor injection), and a readme. Two files show HIGH and MEDIUM risk tampering events with heuristic analysis and forensic reports. All demo data is clearly labelled and completely separate from real monitoring data.

📋 Presentation Workflow Guide
  1. Click Activate Demo Mode — seeds 3 sample files with tamper events
  2. Navigate to Dashboard — show the live forensic activity feed with tamper events
  3. Click Monitored Assets — show the 3 protected files with CLEAN / MODIFIED status badges
  4. Click Inspect Diff on any HIGH risk event — navigate to Change Analysis
  5. Click ✨ Generate AI Threat Advisory — show offline heuristic analysis
  6. Navigate to Forensic Reports — click View Report for a professional incident report
  7. Navigate to Protect Asset — demonstrate the upload-based baseline + verify workflow live
